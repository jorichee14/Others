# SCooP dataset paper

SCooP: A Real-World Indoor Multi-Robot Dataset for Collaborative SLAM and
Perception over Measured Wireless Links. Target: IJRR (Data Paper); fallback: RA-L.

- `main.tex`: manuscript (IEEEtran conference template for drafting)
- `references.bib`: bibliography
- `tables/`, `figures/`: table and figure `.tex` files included by `main.tex`
- `figs/`: figure images (several are still placeholders with dummy data)

Upload the folder to Overleaf as is; `main.tex` is the root file.
