## Command / parameters used (final round)

```bash
ros2 run wicoms_utils radar_camera_calibration --ros-args \
  -p image_topic:=/zed/zed_node/left/image_rect_color \
  -p info_topic:=/zed/zed_node/left/camera_info \
  -p radar_topic:=/radar2/radar/points_all \
  -p pc_field_snr:=intensity -p pc_field_doppler:=doppler \
  -p squares_x:=4 -p squares_y:=4 -p square_len:=0.12 -p marker_len:=0.09 \
  -p dictionary:=DICT_4X4_50 -p min_corners:=4 \
  -p min_range:=0.5 -p max_range:=2.5 -p range_gate_margin_m:=0.5 \
  -p sigma_range_m:=0.05 -p sigma_az_deg:=3.0 -p sigma_el_deg:=8.0 \
  -p radar_range_scale:=1.026 \
  -p reflector_offset_x:=0.26 -p reflector_offset_y:=0.617 -p reflector_offset_z:=-0.044 \
  -p solve_offset:=true -p offset_prior_sigma_m:=0.05 \
  -p use_extrinsic_prior:=true \
  -p prior_t_xyz:="[-0.105,0.0,-0.06]" -p prior_rpy_deg:="[173.30,-75.68,-0.69]" \
  -p prior_t_sigma_m:=0.04 -p prior_rot_sigma_deg:=30.0 \
  -p select_by:=cluster -p cluster_eps:=0.20 -p min_cluster_size:=1 \
  -p cluster_apex_radius:=0.50 -p cluster_strict:=false \
  -p gate_radius:=0.60 \
  -p stable_std:=0.02 -p stable_std_radar:=0.10 \
  -p min_snr:=100.0 -p min_points:=25 \
  -p parent_frame:=zed_left_camera_optical_frame -p child_frame:=radar2_link \
  -p show_window:=true -p show_diversity_hud:=true
```

> `prior_t_x` (−0.10 m) is **tape-measured**, not solved: it is radar2's blind (horizontal) axis, so the data cannot pin it — hence the tight `prior_t_sigma_m:=0.04`. See the jump explanation in the two-radar comparison doc.

**Interpretation:** the *systematic* accuracy is excellent (signed bias ≈ 1 mm on every axis). The large RMS / reproj is the IWR6843's random per-detection angular noise (~3° az, worse el), which **averages out in fusion and tracking** — it is not a calibration error. The horizontal (X = 215 mm RMS) is radar2's soft axis by design (the orthogonal mount); radar1 covers it, and vice-versa. See [`two_radars.md`](two_radars.md).
