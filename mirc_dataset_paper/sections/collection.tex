\section{Dataset Design and Collection}
\label{sec:collection}

\subsection{Environments}
\label{sec:environments}

Data collection was conducted on the Guangfu Campus of National Yang Ming Chiao
Tung University (NYCU), at indoor and outdoor sites. Site selection was governed
by three factors, each associated with a quantity the release reports per frame
rather than with a qualitative descriptor. \textit{Viewpoint}: whether the site
admits vantages displaced from one another---an elevated, persistent
infrastructure position, and mobile nodes able to separate in the ground
plane---characterised by the range of aspect angles $\beta$ realisable between
an ego and a helper, whether that helper is infrastructure or a peer.
\textit{Appearance}: illumination, texture, and clutter density, which determine
the range beyond which $\mathrm{visible}(i)$ ceases to imply
$\mathrm{observed}(i)$ (Eqs.~\eqref{eq:visible}--\eqref{eq:observed}).
\textit{Radio propagation}: whether structure intervenes between a node and the
access point, characterised by first-Fresnel-zone clearance.

Each site is surveyed and mapped once as a dense point cloud, with all node
poses expressed in a single anchored map frame, so that occlusion,
co-visibility, and link geometry are evaluated against a common geometric
representation. The sequence characterised here was recorded at the MIRC site,
an indoor laboratory comprising one surveyed elevated camera--radar mast, a
\SI{5.75}{\giga\hertz} access point positioned behind furniture, and static
seating that constitutes the occluding structure.

\subsection{Collection Protocol}

\subsubsection{Roles}
One mobile agent is designated the \textit{ego} and is viewpoint limited by
design, either by trajectory---routed such that structure intervenes between it
and the annotated objects---or by sensing budget, carrying the shorter-range
depth sensor. The second mobile agent is the \textit{partner}. Ego assignment
alternates across runs, so that a reported condition is attributable to the
geometry rather than to a platform; for the single sequence characterised here,
both ego assignments of the same recording are reported, which is the strongest
form of this control obtainable from one run.

Infrastructure nodes are never assigned the ego role, their function being the
elevated, persistent vantage that no mobile node can sustain. Since comparable
datasets collaborate between sensors at a common height
(Section~\ref{sec:related}), assigning the infrastructure node as ego would
reinstate the symmetry this collection is designed to break.

\subsubsection{Trajectory Paradigms}
\label{sec:paradigms}
A paradigm specifies a trajectory geometry together with the collaboration
condition that geometry is intended to induce. The vocabulary is that of
paradigm-driven multi-robot collection; what is added here is that each paradigm
is a predicate over per-frame quantities, computed from the map, the
annotations, and the node poses, and released with the recordings rather than
asserted of a run.

\paragraph{Per-observation predicates.}
Consider one annotated object at one frame. Let $e$ denote the ego and $j$ range
over the remaining nodes. For node $i$, let $\omega_i \in [0,1]$ denote the
fraction of rays cast from $i$'s sensor origin to the object surface that are
blocked by mapped structure, $r_i$ the range to the object, and $n_i$ the
evidence returns falling within the annotated box (LiDAR points, depth points,
or projected pixel area, according to the node's primary modality). With
$\tau = 0.5$,
%
\begin{align}
\mathrm{visible}(i) &\equiv \text{in FoV} \;\wedge\; \omega_i < \tau,
\label{eq:visible}\\
\mathrm{observed}(i) &\equiv \mathrm{visible}(i) \;\wedge\; n_i \ge n_{\min,i}
\;\wedge\; r_i \le r_{\max,i}.
\label{eq:observed}
\end{align}
%
Visibility is a geometric condition: an unobstructed line exists. Observation is
an evidence condition: the sensor returned support sufficient for a detection,
within the range at which that modality still returns anything. Both have
single-agent precedent as annotation attributes and evaluation filters
(Section~\ref{sec:related}); here they are computed for every node and kept
distinct, so that an object the ego could not see remains separable from one it
could see but for which it returned insufficient evidence. A node may remain
visible and unobserved throughout a sequence, and Section~\ref{sec:results}
shows this to be the dominant failure mode in the present data.

A node $j \ne e$ is a \textit{helper} if $\mathrm{visible}(j)$, and the best
helper $j^\star$ is that of lowest $\omega$. The aspect angle $\beta$ is
subtended at the object between the rays to $e$ and to $j^\star$, so $\beta$
near $0^\circ$ indicates a redundant viewpoint and $\beta > 90^\circ$ a
complementary one. Each frame further records the co-visibility fraction $C$,
being objects visible to at least two nodes over those visible to at least one,
and, for each link, the minimum first-Fresnel-zone clearance against the same
occupancy grid, normalised by the Fresnel radius; $\mathrm{clear}(a,b) < 0.6$
is the obstructed-link criterion.

\paragraph{Labels are descriptive, not prescriptive.}
A paradigm label is assigned per frame from measured metrics, not declared once
per run: a sequence intended as co-observation contains occlusion frames
wherever the geometry produced them, and those frames are labelled accordingly.
Consequently, evaluation strata are cut by the raw metrics and never by the
label. Performance is reported against $\omega$, $\beta$, $r$, $C$, and link
clearance directly; the label serves to describe a run in one word and to permit
intent to be audited. Each run additionally records an
\texttt{intended\_paradigm} in its metadata, and the agreement between intended
and measured is the design check reported in Section~\ref{sec:results}. It
quantifies how reliably a trajectory plan produces the condition for which it
was written.

\paragraph{Use of the released quantities.}
The per-frame quantities are keyed by (\texttt{t\_ns}, \texttt{node},
\texttt{obj\_id}), so that any evaluation over the recordings can be joined to
the condition under which each observation was made. They admit three uses.
They serve as strata: accuracy is reported within bands of $\omega$, $r$,
$\beta$, $C$, or link clearance rather than averaged over the mixture a
recording happens to contain, and a missed object is separable into one the ego
could not see and one it could see but for which it returned insufficient
evidence. They serve as a join between sensing and communication: link state
and perception need are expressed on a common clock, so the value of a
transmission can be assessed at the frame at which it would have been made.
And they serve as an objective: aspect angle, co-visibility, and clearance are
quantities against which a viewpoint, transmission, or placement policy can be
scored directly, so that candidate infrastructure positions and motion policies
are evaluated against recorded trajectories rather than asserted.

\paragraph{Standing parameters.}
The geometric pipeline is frozen across sequences: $\tau = 0.5$; occupancy voxel
\SI{10}{\centi\metre}; 200 rays per object, node, and frame; statistical outlier
removal at 20 neighbours and $2\sigma$; a voxel is occupied only at $\ge 8$
points and a ray blocked only on two consecutive occupied voxels; occluder hits
within \SI{0.6}{\metre} of a sensor origin and occupancy within \SI{0.7}{\metre}
of either link endpoint are disregarded, both nodes and the access point being
themselves present in the map; evidence floors of 1 LiDAR point, 50 depth
points, and 400\,px$^2$; analysis range caps of \SI{20}{\metre} (Ouster),
\SI{4.5}{\metre} (ZED), \SI{5}{\metre} (RealSense), and \SI{20}{\metre}
(infrastructure pixels), each calibrated from the range at which median evidence
falls to its floor; obstructed link below $0.6\,r_1$; carrier frequency read per
frame from the WiFi status stream (\SI{5.75}{\giga\hertz}). Density
thresholding, consecutive-hit testing, and endpoint clearance are workarounds
for map noise and for fixed nodes appearing as mapped structure; they are stated
because they affect the reported values, and a re-analysis against a
survey-grade map should permit their removal.

\subsubsection{Per-Sequence Descriptor}
\label{sec:descriptor}
Each sequence is summarised by one row per ego assignment, in four blocks of
frozen columns. The \textit{design} block records the sequence identifier, the
site, the intended paradigm, any stress factor applied, and which node is ego.
The \textit{geometry} block reports the median co-visibility fraction $C$, the
median aspect angle $\beta$ to the infrastructure node, the proportion of
observations at $\beta > 90^\circ$, and the count of occlusion episodes, an
episode being a contiguous interval of $\neg\,\mathrm{visible}(e)$ on one object
lasting at least \SI{0.5}{\second}, with the number covered throughout by a
helper given in parentheses. The \textit{rescue} block reports the proportion of
ego-in-FoV observations in which a partner supplies what the ego does not:
\textit{occlusion rescue}, where the ego is blocked and a helper is not;
\textit{range rescue}, where the ego holds an unobstructed line but returns
insufficient evidence, $\mathrm{visible}(e) \wedge \neg\,\mathrm{observed}(e)$,
while a helper observes; and \textit{Doppler rescue}, where the ego's radar is
blind to the object's motion and another node's is not. The final block gives
the fraction of frames on which the ego--AP link is obstructed or degraded, and
the median number of annotated objects in view. A quantity undefined for a
sequence is left empty rather than reported as zero. Section~\ref{sec:results}
gives the descriptor for the present release.
