Pringles from the cabinet: task pipeline

Stretch robot + wired room cameras + GPU server · for each step: what runs where, what the room cameras add, and what crosses the robot’s Wi-Fi
Robot: Acknowledge → Navigate to the cabinet → Open the cabinet → Pick up the Pringles → Return to the person → Hand over
Robot runs on the robot   Server runs on the GPU server   |   Wi-Fi: none Wi-Fi: tiny (bytes) Wi-Fi: one photo (~50 KB)

1Acknowledge
Runs on Server
Turns “give me the Pringles from the cabinet” into two targets.
Input: request text · room-camera images
Output: cabinet view pose and person position, each with the time it was seen
Room cameras: find the cabinet and the person
Wi-Fi: tiny (bytes)
Robot → server: request text
Server → robot: the two targets with their times
If late: ask again
➜
Navigate to the cabinet
2Global navigation
Runs on Robot
Nav2 drives to the cabinet view pose. AMCL and the robot’s lidar avoid obstacles.
Input: goal · 2D lidar scan
Output: robot near the cabinet
Room cameras: check the cabinet is still where the map says
Wi-Fi: tiny (bytes)
Robot → server: robot pose (status only)
Server → robot: a new goal, only if the target changed
If late: keep driving to the current goal
3Local navigation
Runs on RobotServer
One photo → handle point (server). Door plane from depth (robot). Rotate – translate – rotate to 0.7 m.
Input: one RGB-D image, robot stopped
Output: robot in position to open the door
Room cameras: —
Wi-Fi: one photo (~50 KB)
Robot → server: one JPEG photo
Server → robot: the handle’s pixel position
If late: take a new photo, ask again
➜
Open the cabinet
4Grasp · open · retract
Runs on Robot
Grasp the handle, swing the door open along its arc, retract the arm.
Input: handle position · door plane
Output: cabinet open, arm clear of the door
Room cameras: —
Wi-Fi: none
nothing crosses the Wi-Fi
➜
Pick up the Pringles
5Detect
Runs on RobotServer
One photo → Pringles mask (YOLOE). Mask × robot depth → 3-D centre.
Input: one RGB-D image · “pringles”
Output: Pringles centre in the robot frame
Room cameras: hint where the Pringles are, if a camera sees inside
Wi-Fi: one photo (~50 KB)
Robot → server: one JPEG photo
Server → robot: the best mask
If late: retry once, then use YOLOE on the robot
6Grasp + lift
Runs on Robot
IK: pre-grasp → approach → close the gripper → lift 10 cm.
Input: Pringles centre · joint states
Output: Pringles in the gripper
Room cameras: —
Wi-Fi: none
nothing crosses the Wi-Fi

7Return
Runs on Robot
Nav2 drives to the person. The goal moves when the person moves.
Input: person position · 2D lidar scan
Output: robot in front of the person
Room cameras: track the person
Wi-Fi: tiny (bytes)
Robot → server: robot pose (status only)
Server → robot: person position when it changes, with its time
If late: slow down near the person, ask for an update
➜
Hand over
8Hand over
Runs on Robot
Hold the Pringles at hand height; open the gripper when the person pulls.
Input: gripper effort
Output: the person holds the Pringles
Room cameras: —
Wi-Fi: none
nothing crosses the Wi-Fi
Nav2, AMCL, obstacle avoidance, depth and the arm all run on the robot. The room cameras are wired to the server, so their images never use the robot’s Wi-Fi. Over Wi-Fi: only targets with their times, one photo per look, and the short answers.
