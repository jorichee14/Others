Pringles from the cabinet: task pipeline

Stretch + wired room cameras + GPU server · what each step does, what the room cameras add, and what crosses the robot’s Wi-Fi
Robot: Acknowledge → Navigate to the cabinet → Open the cabinet → Pick up the Pringles → Return to the person → Hand over

request + room-camera view

1Acknowledge
Person: “Can you give me the Pringles from the cabinet?” The server turns it into targets: the cabinet, the Pringles, and the person to deliver to.
Input: text request; room camera images
Output: cabinet view pose and person position in the map, each with its age
Room cameras: find the cabinet and the person (SAM 3 on the room views, depth from the map)
Link: ↑ request text · ↓ targets + age
➜
Navigate to the cabinet
2Global navigation
Nav2 on the map brings the robot near the cabinet (AMCL on the 2D lidar).
Input: 2D lidar scan; cabinet view pose
Output: the robot is near the cabinet
Room cameras: confirm the cabinet’s position and a clear path; update the target if it changed
Link: ↓ target updates · ↑ robot pose 10 Hz · late → keep last target, slow down
3Local navigation
Gripper camera: handle keypoint + RANSAC door plane. Rotate – translate – rotate to 0.7 m off the door.
Input: one RGB-D image (robot stopped)
Output: the robot is in position to open the cabinet
Room cameras: —
Link: ↑ one JPEG · ↓ handle keypoint (depth stays on the robot) · late → retry
➜
Open the cabinet
4Grasp · open · retract
Grasp the handle, open along the door arc (door radius R, wrist offset r, θ), then retract the arm and lower the wrist.
Input: handle pose; door plane
Output: the cabinet is open and the arm is clear of the door
Room cameras: optional: confirm the door is open
Link: none · runs on the robot
➜
Pick up the Pringles
5Detect
Gripper camera snapshot → YOLOE-seg (“pringles”) → mask × depth → 3-D centre. Small base moves if out of reach; detect again after each.
Input: RGB-D snapshot; prompt
Output: Pringles centre in the base frame
Room cameras: prior: where the Pringles are in the cabinet, if a room camera sees inside
Link: ↑ one JPEG · ↓ best mask (or YOLOE on the robot: nothing) · late → retry once
6Grasp + lift
IK: pre-grasp → approach → close the gripper → lift 10 cm.
Input: object centre; joint states
Output: the Pringles are in the gripper
Room cameras: —
Link: none · runs on the robot
➜
Return to the person
room-camera view of the person

7Return
Nav2 to the person’s position, kept fresh by the room cameras because people move.
Input: person position + age; 2D lidar scan
Output: the robot is in front of the person
Room cameras: live person position; re-sent when the person moves
Link: ↓ person position + age · ↑ robot pose · stale → slow down, ask for an update
➜
Hand over
8Hand over
Raise the Pringles to hand height and hold; open the gripper when the person pulls (gripper effort changes).
Input: gripper effort; person position
Output: the person holds the Pringles
Room cameras: optional: person’s hand position
Link: none · runs on the robot
Room cameras are wired to the server, so they never load the robot’s Wi-Fi. Only targets with their age, one JPEG per look and the answers cross the link; depth, lidar scans and video stay on the robot. Every request carries an ID and capture time.
